## The throughline

Today shipped the entire node-locked commercial-licensing feature end to end:
install-identity fingerprinting → offline Ed25519 key verification → backup
codes for hardware moves → a remote-device cap reconciled against the live
Tailscale API → application-layer and generate/download-time enforcement of
that cap → the dashboard UI for all of it → the real production signing key →
a source-available LICENSE to make the commercial-use restriction legally
real, not just technically enforced. Alongside that, a separate firewall-
hardening batch (Gaps 1-3: scoped VM-adapter rules, tailnet allow rules,
loopback dashboard bind, application-layer source admission) and tailnet
device removal on revoke.

## Judgment calls worth recording

- **Rule 8 caught twice, both fixed before commit, not after.** The tailnet-
  removal test fixtures originally named a real household device and used a
  captured real tailnet address; the cap-enforcement docstrings originally
  spelled out exactly how to defeat the cap (root + defeat-the-probe). Both
  were sanitized and re-verified clean before landing, not shipped and
  patched later.
- **Rule 10 was applied as a standing check, not only when asked.** The
  licensing-engine batch was independently re-verified clean (not just taken
  on Window 1's word). The cap-enforcement batch was NOT clean on first pass
  — real attacker-relevant bypass detail in public docstrings — flagged,
  discussed, and resolved as a public/private split (same treatment as ADR
  0021's rate-limit numbers), with the full text preserved privately for
  eventual commercial documentation.
- **Commit splits were derived from real dependencies, not from naming
  convenience.** The "pasted-key fix" commit turned out to require the full
  seam-1 + seam-2 + stamping + revoke-clearing infrastructure, discovered by
  reading what `test_source_level_wiring` actually asserts, not by guessing
  at scope from the bug's name. A dashboard.py dict-literal hunk that tangled
  two unrelated changes on adjacent lines was hand-split via a crafted patch
  rather than swept in whole.
- **The production signing key got its own commit, verified three
  independent ways** (re-derived from the local private key, re-derived from
  its offline backup, and a real issued license round-tripped through the
  product's own verifier) — nothing about it was taken on trust given how
  much of the licensing system depends on it being exactly right.
