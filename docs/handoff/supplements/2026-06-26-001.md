### Key lessons (now baked into CLAUDE.md)
- **Cross-process callers are a hazard class.** `watchdog.py` runs as its own process, calls
  tickets' `open_ticket()` but never runs `modules_loader.init()` → after cutover `get_db()`
  raised "shared DB path not set" (silently swallowed). Fix: `set_shared_db_path(HW_DB_PATH)`
  before the import. **Grep ALL readers/writers across processes before any cutover.**
  - community_queue was the CLEAN case: every caller (anomaly feeder thread, Flask routes,
    badge) runs in the dashboard process → no cross-process plumbing needed. (hw_monitor's
    hardware anomaly pipeline does NOT feed the queue — verified.)
- **`disable` ≠ quiesce** for modules whose write fns are externally callable (stop() a
  no-op, routes stay registered) → used the read-only-snapshot quiesce (mode=ro + single
  deferred txn) for tickets and community_queue.
- **Live drift vs the ADR:** tickets had 4 rows not 3 (a note added that morning);
  community_queue had 2 not the ADR's 0. Always verify the live count before copying.
