## 3. Security fixes — three bugs from Window 3's audit, plus hardening

`db_action`'s unguarded GET (CSRF-shaped, recorded fake blocks with no real firewall rule),
`api_backup_schedule`'s shell-injection via unescaped crontab interpolation, and
`api_vpn_action`'s unguarded GET were all found by a private route-level audit and fixed in
four commits (`57c09b2`, `ac39e91`, `e8e8f65`, `5719792`) — SameSite/HttpOnly cookie posture,
POST+allowlist+credential gating, `shlex.quote()`+structural rejection of newlines/relative
paths, and POST+JSON-content-type respectively. Independently re-derived and verified against
the actual code before staging, not taken on description — one round caught the actual
working-tree diff not matching what was described (extra idle-lock scaffolding mixed in) and
required a hand-split via `git apply --cached` on a trimmed patch.

Two new standing CLAUDE.md rules came out of this work: a route-level security audit that
triggers automatically on any `dashboard.py`/routes/templates change (`e281a72`, later
corrected to drop private-mirror filenames per Rule 10 — `31a15f2`), and a verification-code
discipline rule after nine instances in one day of the same failure shape — an instrument
that can only produce one answer, reporting that answer as a measurement (`68124dd`).

## 4. ADR 0019 — Increments 3 and 4, the big arc of the day

- **Increment 3 (counter agreement):** went from "not yet started" through "attempted, all
  inconclusive" (`f9c4c95`, `7c23ba8`) to **PROVEN** (`ad8be0f`, `90fda93`) after five total
  attempts — four invalid for distinct reasons (table lost at reboot, zero blocks, silent
  peer, synthetic traffic hitting an existing conntrack entry) before a correctly-isolated,
  packet-capture-verified fifth run passed. A false FAIL along the way was traced to and
  retracted as a harness bug (two sides of the comparison keyed the same address in different
  text formats).
- **Persistence + integrity:** a systemd unit re-establishes the enforcement table at boot
  (`357e99c`), and a netlink watcher detects out-of-band changes to it — VM-verified across
  the "kill watcher, tamper while down, restart, caught on startup re-verify" bypass test
  (`2a3569d`).
- **Never-block guard:** `nemesis-fw-render` now classifies every derived address through
  the same authoritative list the live chokepoint uses, self-tests four canaries every run,
  and fails closed (exit 3, output file untouched) if it can't run (`bc64988`).
- **Increment 4 (verdict emission):** shipped gated OFF by default (`df24480`) — production
  unaffected. **Cutover (flipping the default on) was attempted and is HELD, not pushed** —
  see §5.
- A second, independent justification for Increment 4 emerged mid-day: a confirmed conntrack
  bypass in the *current* interim block mechanism (established connections survive a `ufw`
  block). Kept private per Rule 10 throughout — the public ADR states its existence and that
  Increment 4 closes it, never the mechanism.
