Before you install

Nemesis Security Agent for Windows

Windows will show you one or two security warnings during this install. They are expected, and this page shows you exactly what they look like before you meet them — so you can tell a normal prompt from a genuine problem.

Why they appear at all

Windows warns about any program it has not seen many times before. Nemesis is self-hosted software installed by a small number of people, so Windows has no widespread history for it and treats it as unfamiliar. That is a statement about how many people have downloaded this file — not about whether it is safe.

Warning 1 — may or may not appear

“Windows protected your PC”

Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk.

More info
Don’t run

This one is a full-screen blue box, and at first it looks like there is no way forward — the only button is Don’t run.

What to do: click More info (the small link in the middle of the text), which reveals a Run anyway button underneath.
Warning 2 — will always appear

“Do you want to allow this app…”

User Account Control Do you want to allow this app from an unknown publisher to make changes to your device?
NemesisAgent-Setup.exe
Publisher: Unknown
File origin: Downloaded from the Internet
YesNo

This smaller yellow-topped box always appears, because installing the agent genuinely does need administrator permission — it sets up a background service that monitors this device. Note that Windows highlights No as the default.

What to do: click Yes to continue the install.

What these warnings do not mean

  • They do not mean a virus was found. Nothing was detected — if Windows had actually found malware, it would say so plainly and remove the file rather than ask you.
  • They do not mean the file is damaged or that the download failed.
  • They do not mean something is wrong with your computer.
  • “Unknown publisher” means the file carries no purchased publisher signature yet. It is a statement about paperwork, not about behaviour.
One thing genuinely worth checking first. These prompts exist for a good reason, and we are not asking you to ignore them in general — only to recognise this specific, expected one. Continue only if you reached this page from a link your own administrator gave you. If you found it somewhere else, or you were not expecting to install anything, stop here and ask them first. Never turn off Windows Security, Defender, or SmartScreen to get past a warning — not for this install, and not for any other.
