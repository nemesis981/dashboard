Default set for new trainees

Topics marked in default set are assigned automatically the first time an account is given the user role or above. This happens once per account: an assignment you remove by hand will not come back the next time that person’s role changes.

Existing accounts are not updated automatically. Use Preview below to see exactly what would change, then Apply. Applying only ever adds — it never removes an assignment you made by hand.
